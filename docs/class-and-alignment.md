# Class And Alignment

Oathstar should not use fixed starting classes.

Instead, class identity should emerge from what the player learns, practices, swears, breaks, helps, harms, and becomes.

## Emergent Classes

The player begins from a neutral identity, such as Oathbearer.

Over time, the game can recognize class identities based on:

- Skill percentages
- Unlocked skills
- Oaths fulfilled
- Oaths broken
- Region standing
- Traits
- Transformations
- Important choices

Example:

```text
High sword skill
High healing skill
Fulfilled faith/mercy oaths
Good standing in sacred regions
High strength
=> Holy Knight
```

Alternate example:

```text
High sword skill
Forbidden ritual skills
Broken mercy oaths
Hostile sacred standing
High strength
=> Dark Knight
```

## No Rigid Starting Class Lock

The player should not be bound forever by an initial class choice.

Class identity is discovered and recognized.

The player can potentially pivot by:

- Training different skills
- Changing oath behavior
- Repairing or ruining region standing
- Completing class-defining trials
- Mastering a previous class path
- Undergoing transformation

## Class Mastery

Class mastery can be designed later.

Possible future uses:

- Unlock powerful class skills
- Unlock godlike or mythic abilities
- Allow pivoting into related classes
- Mutate existing abilities
- Grant titles, region reactions, or oath authority
- Open transformation paths

## Transformations

Transformations are major identity changes. Some may be irreversible or difficult to reverse.

Examples:

- Vampire-like curse
- Tech infusion
- Star-touched body
- Oathbreaker brand
- Saint of glass
- Ironbound limb
- Ashen heart

Transformations can affect:

- Skills
- Class eligibility
- Region standing
- NPC reactions
- Combat abilities
- Oath permissions
- Weaknesses
- Endings

## Alignment

Oathstar should have an action-driven alignment system inspired by good/neutral/evil and lawful/neutral/chaotic axes.

The system should change based on behavior, not a starting menu choice.

Suggested axes:

- Moral axis: Good, Neutral, Evil
- Order axis: Lawful, Neutral, Chaotic

Examples:

- Keeping mercy oaths may move toward Good.
- Keeping court/law oaths may move toward Lawful.
- Breaking oaths, betrayal, cruelty, or predatory choices may move toward Evil.
- Defying institutions, violating region laws, or rejecting witnesses may move toward Chaotic.

Alignment should influence:

- Emergent class recognition
- NPC reactions
- Region standing
- Oath availability
- Transformation eligibility
- Boss resolutions
- Endings

## Design Guardrails

- Alignment should reflect actions, not railroad them.
- The player should be able to drift, recover, fall, or transform.
- Alignment should not replace specific oath consequences.
- Major irreversible changes should be clearly foreshadowed.
- Class titles should be cool, but not trap the player in a boring lane.

## Open Questions

- Should alignment be visible as exact labels or inferred through title/region reactions?
- Should alignment be numeric under the hood?
- How easy is it to recover from Evil or Chaotic reputation?
- Do some classes require stable alignment over time?
- Can class mastery override alignment requirements?
